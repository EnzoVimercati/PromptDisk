# PromptDisk

Biblioteca de prompts de IA e arquivos `.md` para desenvolvedores.

## Estrutura

```
content/
├── design/        # Designs completos
├── components/    # Botões, cards, etc.
├── architecture/  # Arquitetura de código
└── utility/       # Utilities
```

## Como funciona

1. Clone o repositório
2. Navegue pelos `.md` na pasta `content/`
3. Use o prompt na sua ferramenta de IA (Cursor, Claude Code, etc.)

## Stacks

- React + Tailwind CSS
- HTML/CSS/JS puro

## Tecnologias testadas

Claude • Cursor • GPT-4 • Claude Code • GitHub Copilot
